# 涌线 -- crowd line

**涌现式地铁调度沙盒**。以真实城市线网为舞台，玩家只调规则（限流、加车、封站、广播……），乘客自己涌、自己堵、自己疏解，最终以积分评价经营水平。

> 基于《涌线--crowd line》游戏策划案 v0.2 实现的 Godot 4.7.2 可玩 Demo。

---

## 快速开始

1. 用 **Godot 4.7.2** 打开本项目（`project.godot`）。
2. 直接运行主场景 `res://scenes/main.tscn`（F5）。
3. 主菜单选择线网与难度池，点击「开始运营」。

> 引擎定位：`F:\Godot_project\涌线--crowd-line\`。渲染方式为 Mobile（兼容移动端），Windows 驱动 d3d12。

---

## 操作说明

| 输入 | 动作 |
| --- | --- |
| 鼠标滚轮 | 缩放（三段式视野：远景成分云 → 中景 → 近景站点） |
| 左键拖拽 | 平移视野 |
| 左键点击站点 | 选中站点（显示限流 / 封站 / 跳站） |
| 左键点击线路 | 选中线路（显示加车） |
| 点击空白 | 取消选择 |
| 底部按钮 | 限流、加车、封站、跳站、广播 |

## 已实现功能（对照策划案 v0.2）

### 核心循环与涌现
- 乘客 Agent：最短路径寻路（BFS）、耐心衰减、从众性、恐慌传播。
- 列车：沿线运行、班次、容量、登降、**延误传播**（晚点列车在换乘站波及其他线路）。
- 站点：容量上限、密度阈值、换乘。
- 涌现：限流→需求转移、加车→运力变化、封站→人流改道、恐慌→踩踏风险。

### 时间变化系统（v0.2 新增）
- 昼夜循环：清晨 / 早高峰 / 平峰 / 午间 / 午后 / 晚高峰 / 夜间 / 深夜。
- 时间驱动参数：需求曲线、耐心衰减速率、从众性、背景色平滑过渡。
- 天气系统：晴 / 阴 / 小雨 / 暴雨 / 雪 / 雾，叠加需求与速度倍率，GPU 粒子（雨 / 雪）。

### 三段式视野与成分云
- 远景：乘客合并为半透明「成分云」，颜色表示状态构成，密度表示压力。
- 中景：乘客为小圆点，线路与站点清晰（Mini Metro 风格）。
- 近景：放大可见站点环、恐慌高亮、列车满载指示。
- 缩放过渡：云 ↔ 圆点交叉淡入淡出。

### 玩家操作
限流（降低进站速率）、加车（消耗资源提升运力）、封站（强制改道）、跳站（列车不停靠）、广播（平息恐慌 / 引导改道，长冷却）。

### 积分评价
准点率（25%）、满意度（25%）、吞吐量（20%）、安全分（20%）、效率分（10%），评级 D/C/B/A/S。

### 肉鸽机制（只改参数）
- 随机事件：演唱会散场、暴雨、信号故障、出口关闭、票价优惠、设备检修。
- 每 2 分钟三选一升级：快速闸机、智能广播、备用列车、宽敞站台、应急通道。

### 失败条件
踩踏风险、全网瘫痪、满意度归零。

### 线网
- 入门池：温州 S1 线（7 站，单线）。
- 进阶池：香港 荃湾线 + 观塘线（18 站，2 换乘）。

## 目录结构

```
涌线--crowd-line/
├── project.godot            # 工程配置（autoload、主场景、渲染）
├── README.md                # 本文件
├── docs/                    # 项目规范、架构说明
├── scenes/                  # 场景（main.tscn 为唯一手写场景，其余程序化构建）
├── scripts/
│   ├── main.gd              # 入口状态机：菜单 → 游戏 → 结算
│   ├── game.gd              # 单局编排（组装模拟/渲染/UI）
│   ├── config.gd            # 常量与调色板、时间曲线、难度预设
│   ├── autoload/            # EventBus（信号总线）、AppState（持久状态）
│   ├── simulation/          # 模拟层：Agent、列车、站点、时间、天气、积分、事件
│   ├── rendering/           # 渲染层：GameView、相机、天气粒子
│   └── ui/                  # HUD、主菜单、结算、升级
├── resources/networks/      # 线网 JSON 数据（真实站点拓扑）
└── asset/                   # 外部素材（当前 Demo 全部程序化绘制，无需贴图）
```

---

## 线网数据格式

见 `resources/networks/*.json`，包含站点（名称、坐标、容量）与线路（颜色、班次、站点序列）。换乘站由「同站点出现在多条线路」自动推导。详见 [docs/项目规范.md](docs/项目规范.md)。

## 已知简化

- **美术**：Demo 全部采用程序化绘制（`_draw`），未引入外部贴图；策划案中的地标剪影、手绘图标、音频基调未实现（后续可替换为素材）。
- **无限模式**：未实现（仅入门 / 进阶 / 硬核三个难度池）。
- **移动端缩放 UI**：目前仅实现滚轮缩放，右侧拖动缩放待补。
- **着色器**：昼夜用代码 `lerp` 调色实现，未用全屏 shader；Bloom 用多层半透明圆近似。
